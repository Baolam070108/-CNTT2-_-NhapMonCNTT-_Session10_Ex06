Nam mắc hai sai lầm khi sử dụng file Word (.docx) cho dự án GreenTech:
- Sai lầm 1: Sử dụng Rich Text thay vì Plain Text. File Word chứa nhiều dữ liệu định dạng phức tạp, còn Markdown sử dụng văn bản thuần với cú pháp đơn giản, nhẹ và có thể hiển thị trực tiếp trên GitHub.
- Sai lầm 2: Chưa hiểu cách Git quản lý phiên bản. File Word khó so sánh thay đổi vì dữ liệu nhị phân, dễ gây xung đột khi làm việc nhóm. Markdown cho phép Git Diff xác định chính xác những dòng được thêm, xóa hoặc sửa.
Kết luận: Markdown nhẹ, dễ đọc, thuận tiện quản lý phiên bản. Khi mất một byte, Markdown thường vẫn đọc được phần nội dung còn lại, trong khi file Word có thể bị hỏng nếu dữ liệu cấu trúc quan trọng bị ảnh hưởng
